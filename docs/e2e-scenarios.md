# Scenarios

- Organizer: the event they created is on the management page.
- Participant: the hackathon they joined is readable.
- Team: the teammate board opens.
- Judge: the scoring console opens.
- Voter: the ballot page opens.
- Observer: the public hackathon page opens without an account.
- Settlement: results stay readable after the prize is paid.
- Vote sealed: the ballot is not revealed before the reveal.
- Cancellation: a cancelled event says that it was cancelled.
- Disqualification: the project remains in the results. The decision is a record, not a deletion.

Each one signs only through the wallet stub, which calls `assertTestKey`.
